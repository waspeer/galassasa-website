## 2. Breaking-change work items
- **Astro 5**: `src/env.d.ts` no longer generated; tsconfig gets `include: [".astro/types.d.ts","**/*"]`, `exclude: ["dist"]`. `security.checkOrigin` now defaults true (no forms here, fine). `output: 'server'` unchanged.
- **Astro 6**: node >=22.12, Vite 7, `import.meta.env` always string. `<Image>` crops by default, never upscales.
- **Astro 7**: Vite 8 + Rolldown/Oxc, Rust compiler only (stricter HTML — audit all 8 .astro files), **`compressHTML` default `true` -> `'jsx'`** which eats whitespace between inline elements -> set `compressHTML: true` explicitly.
- **@astrojs/netlify 8**: peer astro ^7. `imageCDN` default true -> remote domains must be authorised via `image.domains` / `image.remotePatterns`.
- **picosanity 5 / @sanity/image-url 2**: rewrite imports in `web/src/lib/sanity.ts` + `web/src/lib/types.ts`.
- **postcss-preset-env 11**: rename `web/postcss.config.cjs` -> `.mjs`, ESM imports, keep nesting working (`features: { 'nesting-rules': true }`; the CSS modules use `&`-nesting and `@custom-media` heavily).
- **Sanity 6**: `sanity/tsconfig.json` `moduleResolution: "node"` -> `"bundler"` (otherwise `sanity/structure` subpath does not resolve).
- **znv removal**: `env` schema into `astro.config.mjs`, `import { SANITY_PROJECT_ID, SANITY_DATASET } from 'astro:env/server'`.

## 3. Bugs / cleanups spotted (separate `fix:` commits)
1. `layout.astro` Cache-Control header is malformed: `'public, s-max-age=300 stale-while-revalidate=604800'` — `s-max-age` is not a directive (`s-maxage` is) and the comma between directives is missing, so both directives are dropped by caches.
2. Root `package.json` dev scripts call `yarn workspace ...` in a **pnpm** workspace — `pnpm dev` is broken.
3. `web/pnpm-lock.yaml` — stale nested lockfile (lockfileVersion 6.0) inside a pnpm workspace; must not exist.
4. `sanity/.sanity/runtime/{app.js,index.html}` — generated by `sanity dev`, accidentally committed. Delete + gitignore `.sanity`.
5. `web/src/pages/over-ons/[personId].astro` exports `getStaticPaths` on a non-prerendered route in an `output: 'server'` project — dead code.
6. `Astro.params.personId` (`string | undefined`) is passed where `string` is required + used as an index into `Persons`.
